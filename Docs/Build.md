## 18. 추가 반영된 누락 항목

이 문서의 이전 버전에는 현재 코드에 있는 몇 가지 구현 요소가 빠져 있었습니다. 아래 항목은 실제 구현 기준으로 추가 보강한 내용입니다.

### 18.1 브라우저 런타임 호스트 계층

브라우저 타깃은 단순히 `BrowserRenderDevice`만 추가된 구조가 아닙니다. 런타임 호스트도 별도 구현을 가집니다.

- `BrowserRuntimeHost`
- `BrowserGraphicsDeviceFactory`

`BrowserRuntimeHost`는 `IRuntimeHost` 구현체이며, 브라우저 그래픽스 디바이스 생성, 오디오 런타임 연결, `minimalMode` 전달을 담당합니다. 브라우저에서는 SDL 이벤트 부착 대신 JS 입력 브리지가 동작하므로 `AttachInput(...)`는 비워 둡니다.

### 18.2 `BrowserEntry`의 실제 역할

`BrowserEntry`는 단순 부트스트랩 함수만 제공하지 않습니다. 현재 다음 기능을 가집니다.

- 런타임 초기화: `InitializeRuntime()`
- 프레임 진행: `TickFrame()`
- 종료 여부 확인: `ShouldClose()`
- 상태 문자열 출력: `GetDebugState()`
- 씬 디버그 덤프: `GetSceneDebugDump()`
- 입력 초기화: `ResetInputState()`
- DOM 입력 브리지: `OnKeyDown`, `OnKeyUp`, `OnMouseMove`, `OnMouseDown`, `OnMouseUp`, `OnMouseWheel`

또한 최근 엔진 로그를 내부 큐에 모아 상태창에 같이 내보냅니다.

### 18.3 브라우저 리소스 빌더들

브라우저 백엔드는 프로그램과 텍스처만 분리된 것이 아닙니다. 아래 빌더 구현도 실제로 존재합니다.

- `BrowserRenderTextureBuilder`
- `BrowserRenderTargetBuilder`
- `BrowserRenderMeshBuilder`
- `BrowserRenderMesh`
- `BrowserRenderTarget`

즉 브라우저는 `RenderTextureBuilder`, `RenderTargetBuilder`, `RenderMeshBuilder` 계층까지 모두 대체 구현을 사용합니다.

### 18.4 에디터 웹 실행 경로

`BuildManagerWindow`는 현재 다음 버튼 동작을 포함합니다.

- `Build`
- `Build And Run`
- `Run Existing Build`
- `Open Build Folder`

웹 타깃에서 `Run Existing Build`는 새 퍼블리시 없이 기존 산출물을 다시 실행하는 용도입니다. 이때 에디터 내부의 `WebBuildPreviewServer`가 `HttpListener` 기반 localhost 정적 서버를 띄우고, 브라우저에서 `index.html`을 엽니다.

### 18.5 브라우저 텍스처 생성 기본 규칙

`graphics.js` 기준 현재 브라우저 텍스처는 다음 규칙으로 생성됩니다.

- `RGBA`
- `CLAMP_TO_EDGE`
- `LINEAR` 또는 `NEAREST`
- `UNPACK_ALIGNMENT = 1`

이는 스타일 셰이더, UI 텍스처, 포스트프로세스 텍스처까지 포함한 브라우저 텍스처 경로의 공통 규칙입니다.
